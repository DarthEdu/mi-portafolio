# Portafolio de Eduardo Porras

Mi portafolio personal como desarrollador de software, graduado de la ESFOT-EPN.

## Características

- 🌙 Modo claro/oscuro con persistencia en localStorage
- 📱 Diseño responsive (mobile-first)
- 🃏 Tarjetas de proyectos con enlaces a GitHub
- 🏆 Sección de certificados de Credly
- 🔐 Meta tags de seguridad
- 📊 Sitemap y robots.txt para SEO
- ✨ Animaciones suaves

## Tecnologías

- HTML5
- CSS3 (BEM + Design System)
- JavaScript (Vanilla)
- Bootstrap 5
- FontAwesome 6

## Estructura

```
portafolio/
├── index.html      # Estructura principal
├── app.js          # Lógica (skills, proyectos, certificados, theme)
├── style.css       # Estilos con metodología BEM
├── robots.txt      # Reglas para crawlers

```
